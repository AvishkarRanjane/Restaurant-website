# DELICIOUS Restaurant Website

A professional and modern restaurant website showcasing culinary excellence with an elegant user interface and smooth user experience.

## 📋 Overview

DELICIOUS is a fully responsive restaurant website built with HTML, CSS, and JavaScript. It features a contemporary design with smooth animations, parallax effects, and an intuitive navigation system.

## 📁 Project Structure

```
Restaurant website/
├── index.html           # Home page - Main landing page with featured dishes
├── menu.html            # Menu page - Browse full restaurant menu
├── about.html           # About page - Restaurant information and story
├── services.html        # Services page - Restaurant services and offerings
├── membership.html      # Membership page - Membership programs and benefits
├── gift-cards.html      # Gift cards page - Gift card information
├── privacy.html         # Privacy policy page
├── style.css            # Main stylesheet - All styling and responsive design
├── script.js            # JavaScript functionality - Animations and interactions
└── README.md            # This file
```

## 🎨 Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations** - Reveal animations and parallax scrolling effects
- **Modern UI** - Clean, professional interface with elegant typography
- **Interactive Navigation** - Easy-to-use navigation menu across all pages
- **Food Showcase** - Beautiful grid layout displaying dishes with descriptions
- **Category Filters** - Browse food items by category (Appetizers, Main Dish, Dessert)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional installations required

### How to Use

1. Open `index.html` in your web browser to view the website
2. Use the navigation menu to explore different pages
3. Browse menu items, learn about the restaurant, and check membership options
4. All pages are fully functional and interactive

## 🎯 Key Features Explained

### Parallax Scrolling
Floating images move at different speeds as you scroll, creating depth and visual interest.

### Reveal Animations
Elements animate into view as they enter the viewport for a smooth, engaging experience.

### Responsive Design
The website automatically adapts to different screen sizes for optimal viewing on all devices.
